# Лабораторная работа №1 — Обработка строки символов различными способами хранения

## Информация о проекте

| | |
|---|---|
| **Тема** | Обработка строки символов различными способами хранения |
| **Цель** | Изучить способы хранения и обработки строк в C/C++: массивы символов, строки в стиле Си (`'\0'`), данные в файле. Освоить работу с `char[]`, C-строками и файловым вводом/выводом |
| **Назначение** | Три самостоятельные программы, демонстрирующие один и тот же алгоритм обработки строки на трёх разных способах хранения, с модульными тестами |
| **Индивидуальный вариант** | **8.** Найти все символы между первым и последним двоеточием в строке. Если двоеточие только одно — вывести все символы после него и поменять местами первую и последнюю букву строки |
| **Язык / стандарт** | C++17, CMake 3.16+, Catch2 v2 (vendored) |

### Правила обработки (вариант 8)

Пусть в строке есть первое двоеточие (индекс `first`) и последнее двоеточие (индекс `last`):

1. **Двоеточий два и больше** — вывести все символы строго между ними: `s[first+1 .. last-1]`.
2. **Двоеточие ровно одно** — вывести все символы после него: `s[first+1 .. конец]`, а затем поменять местами первую и последнюю **буквы** всей строки.
3. **Двоеточий нет** — сообщить об этом.

«Буква» — латинский символ, для которого истинно `isalpha()`, либо кириллический символ
в UTF-8 (два байта со старшим байтом `0xD0`/`0xD1`). Обмен букв выполняется на месте,
без дополнительных массивов.

## Техническое задание

Написать три программы для обработки строки символов, используя разные способы хранения:

1. **Строка как массив символов** — одномерный массив `char[]`; обработка только по
   исходному массиву, дополнительные массивы вводить нельзя.
2. **Строка в стиле языка Си** — строка завершается символом `'\0'`; обработка без
   дополнительных массивов.
3. **Строка хранится в файле** — строка читается из файла 1, обрабатывается по первому
   или второму варианту, результат записывается в файл 2; файлы не временные (сохраняются
   после работы программы); дополнительные массивы запрещены.

Требования:

- все операции — только с исходным массивом/строкой;
- ввод строки пользователем (варианты 1 и 2) либо чтение из файла (вариант 3);
- в варианте 3 результат записывается в файл;
- каждая программа покрыта тестами на том же файле `catch.hpp`, что и в работах
  по семинарам курса (он скопирован в `laboratory1/external/catch2/catch.hpp`);
- структура проекта соответствует структуре семинара;
- все три программы — в общей папке `laboratory1`;
- для файлов — стандартные функции C: `fopen()`, `fgets()`, `fputs()`, `fclose()`;
- код максимально простой и лаконичный.

## Архитектура проекта

```
        program_array   program_c_string   program_file
              │                │                │
              │                │          process_file() ──► process_c_string()
              ▼                ▼                │
        process_array()  process_c_string() ◄────┘
              │                │
              └───────┬────────┘
                      ▼
             swap_first_last_letters()      (string_utils)
```

- **`string_processing`** — статическая библиотека со всей логикой. Каждый вариант
  хранения реализован отдельным модулем; модули не знают друг о друге, кроме того, что
  вариант 3 намеренно переиспользует обработку варианта 2 (задание прямо это разрешает).
- **`programs`** — три тонких исполняемых файла: чтение входа и вызов соответствующей
  функции обработки. Вся работа со строкой остаётся в библиотеке.
- **`tests`** — один бинарник `string_tests` со всеми тестами на Catch2 v2
  (`main()` задаётся через `CATCH_CONFIG_MAIN` в `test_array_string.cpp`),
  зарегистрирован в CTest.
- Общие функции обработки пишут результат в переданный `FILE* out`: программа 1 и 2
  передают `stdout`, программа 3 — открытый файл результата, тесты — `tmpfile()`.
  Поэтому тесты проверяют точный текст вывода, не подменяя логику.

## Пояснения к основным модулям кода

### `string_utils.h / string_utils.cpp`
- `kMaxLineLength` — размер буфера под читаемую строку (4096 с учётом `'\0'`).
- `swap_first_last_letters(char* s, size_t len)` — находит первую и последнюю букву
  одним проходом (латиница через `isalpha()`, кириллица — по признаку двухбайтового
  символа UTF-8) и меняет их местами **на месте**: четыре разворота участков массива
  (`reverse`) — без единого дополнительного массива. Ширина букв может отличаться
  (1 байт против 2), поэтому используется именно разворот, а не обмен байтов.

### `array_string.h / array_string.cpp` — вариант 1
Работает только с массивом и его явной длиной `len`: `'\0'`, `strlen()`, `strchr()`
не используются. Первое и последнее двоеточие ищутся одним проходом по массиву
(`first == len` означает «двоеточий нет»). Результат выводится побайтово через
`fputc()`.

### `c_string.h / c_string.cpp` — вариант 2
Работает с строкой, завершающейся `'\0'`: границы ищутся стандартными
`strchr(s, ':')` и `strrchr(s, ':')`, хвост после двоеточия выводится целиком через
`fputs(first + 1, out)`. Для случая единственного двоеточия результат подписывается
двумя строками: `Срез после двоеточия: <хвост>` и `Обработанная строка: <строка после
обмена букв>` — этот же формат получают программа 2, файл `file2.txt` и тесты
`[c_string]`/`[file]`.

### `file_string.h / file_string.cpp` — вариант 3
`process_file(in_path, out_path)`: открывает входной файл через `fopen()`, читает
единственную строку через `fgets()` в один массив, убирает перевод строки, открывает
выходной файл и вызывает `process_c_string()` с потоком результата. Ничего не
удаляется — `file1.txt` и `file2.txt` остаются после работы программы.

### `programs/*.cpp`
- `program_array.cpp` — читает строку с клавиатуры и сам вычисляет длину массива
  (до `'\n'` или конца буфера), не опираясь на `'\0'`;
- `program_c_string.cpp` — читает строку и нормализует её через `strcspn(s, "\n")`;
- `program_file.cpp` — вызывает `process_file("file1.txt", "file2.txt")`.

### `tests/*.cpp`
Тесты обёрнуты в helper `process()`: строка копируется в локальный `char[]`, функция
обработки пишет в `tmpfile()`, затем сравниваются точный вывод и итоговое содержимое
массива. Покрыты: пустая строка, отсутствие двоеточий, одно/два/несколько двоеточий,
двоеточие на границе, соседние двоеточия, строки без букв, кириллица, разная ширина
букв, отсутствующий и пустой входной файл.

### Примеры работы

**Программа 1 — `program_array`** (строка как массив символов) выводит только результат:

| Вход | Вывод |
|---|---|
| `до:слово:после` | `слово` (двоеточий два — символы между ними) |
| `a:b:c:d` | `b:c` |
| `привет:мир` | `мир`<br>`рривет:мип` (символы после двоеточия + обмен первой и последней буквы) |
| `ab:cd` | `cd`<br>`db:ca` |
| `abcdef` | `Двоеточий в строке нет` |

**Программы 2 и 3 — `program_c_string`, `program_file`** (C-строка и файл) для случая
единственного двоеточия дополнительно подписывают обе части результата:

| Вход | Вывод |
|---|---|
| `до:слово:после` | `слово` |
| `привет:мир` | `Срез после двоеточия: мир`<br>`Обработанная строка: рривет:мип` |
| `ab:cd` | `Срез после двоеточия: cd`<br>`Обработанная строка: db:ca` |
| `abcdef` | `Двоеточий в строке нет` |

Входной файл `file1.txt` содержит `Пример:строки:для:файла`, после запуска
`program_file` в `file2.txt` записывается:

```
строки:для
```
